# Как добить русский перевод

Словарь — обычный JSON. Ничего компилировать не нужно.

Файл: `BepInEx/config/PPKit/ru.json` (создаётся при первом запуске игры).

```json
{
  "strings": {
    "Settings": "Настройки",
    "Quit Game": "Выйти из игры"
  }
}
```

- **Ключ** — ровно тот текст, который игра присваивает UI-компоненту (регистр важен).
- **Значение** — русский текст.
- `// комментарии` разрешены.
- Применяется по `F5` в игре. Перезапуск не нужен.
- Внешний файл главнее встроенного в DLL — свои строки можно добавлять, встроенные переопределять.

## Рабочий цикл

1. Открыть в игре экран, который нужно перевести.
2. `F12` — получить `BepInEx/config/PPKit/strings_dump.txt`:
   строки со `[x]` уже переведены, с `[ ]` — ещё нет.
3. Добавить нужные пары в `ru.json`.
4. `F5` — проверить.

Чтобы не гоняться за каждой строкой: включить в конфиге
`02. Язык → Писать непереведённые строки` — все встреченные непереведённые строки
будут копиться в `BepInEx/config/PPKit/missing_strings.txt`.

## Что мод намеренно НЕ переводит

Строки, похожие на технические идентификаторы (настройка `Не трогать ID и пути`):

- длиннее 120 символов;
- содержат `/` или `\` (пути, ресурсы);
- `snake_case` без пробелов;
- заканчиваются на `.png`, `.prefab`, `.json`.

Игра и моды используют такие строки как ключи для поиска ассетов и сохранений —
их перевод ломает загрузку. Если что-то нужное не переводится, добавьте строку
в словарь явно: явное совпадение приоритетнее эвристики.

## Если вместо букв квадраты

Своё меню мода (`F1`) берёт шрифт из системы: `02. Язык → Шрифт меню PPKit`.
Поставьте `Arial`, `Tahoma` или `Segoe UI`. Текст самой игры рисуется её собственным
шрифтом — если в игре нет кириллических глифов, никакой словарь не поможет,
это ограничение шрифта игры, а не мода.

## Хотите выложить перевод отдельно

Возьмите `src/PPKit/Loc/ru.json`, оставьте только блок `strings` — этого достаточно
как отдельный языковой пак (CC0). Пожалуйста, не прикладывайте к нему файлы игры.
